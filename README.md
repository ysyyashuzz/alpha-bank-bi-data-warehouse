Alpha Bank BI & Data Warehousing Case Study

 Overview
Case study of a retail bank's transition to a modern BI and data warehouse architecture, done as part of a university course project.

 Goal
- Solve legacy BI issues
- Design conformed dimensions and fact tables
- Propose ETL and data transformation strategy
- Recommend OLAP/visualization use cases

 Key Concepts
- Dimensional modeling (star schema)
- ETL transformations
- Conformed dimensions
- BI dashboards and reporting roles
